= Linux Base

== Kernel Command Line

Any layer may contribute kernel command line arguments as fragments in its `cmdline.d` drop-in directory for this layer, ie static fragments in `<layer-stem>.d/for/linux-base/cmdline.d/` and dynamic fragments written at build time to `$LAYER_WORKDIR/for/linux-base/cmdline.d/`, no later than `preimage`. See _Drop-ins for Other Layers_ in the layer documentation for version-specific directories, precedence and ordering.

A fragment is a single line of whitespace separated arguments. `-glob` removes matching arguments contributed earlier (eg `-fsck*` removes `fsck.repair=yes`). `+arg` or `arg` appends an argument. The result is written to `/etc/kernel/cmdline`.
